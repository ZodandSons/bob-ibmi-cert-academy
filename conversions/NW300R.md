## Behaviour notes for testers

- The subfile loads identically: SETLL on POSKEY, READ loop up to 500 records, same EOF/limit exit.
- The CHGREC and ADDREC retry loops (`dou not in50`) behave the same as the original `CABEQ *IN50 CHG1`/`ADD1` pattern — loop until no edit errors, or until F3/F12 pressed.

- `datedit(*mdy)` is carried over; date display format is unchanged.
- `dftactgrp(*no)` is added (required for subprocedures). The original had no ACTGRP keyword, meaning it ran in the default activation group. **If this program is called from another program in a named activation group, verify file sharing and override behaviour are unaffected.**
